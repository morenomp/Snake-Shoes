# 📌 **Resumen del proyecto**
¿De qué consta?

    Snake Shoes es una marca ficticia de calzado deportivo creada como 
    proyecto personal de branding digital y diseño web.  
    El objetivo era desarrollar una identidad visual fuerte y una web 
    minimalista y dinámica que reflejara un producto moderno y con estilo.

    El diseño, las animaciones, el logotipo y toda la estructura web 
    han sido desarrollados desde cero, aplicando principios de UI/UX 
    y enfoque mobile-first.

¿Quién es el cliente?

    No existe un cliente real. Snake Shoes es un concepto propio, 
    diseñado para explorar la relación entre marca, narrativa visual 
    y experiencia digital en el entorno e-commerce.
